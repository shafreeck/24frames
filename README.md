# 二十四格 24frames

一秒钟拆成 24 格，每一格都得有名字。这里收的是 AI 影像里那些本来就有名字的运镜与风格。

AI 让一个人也能做一部片子，但非专业的人缺的不是技术，是**词**——不知道那个运镜叫什么，就没法让模型精确还原。这个站压缩的就是这一段：从「说不清的画面」到「一个模型听得懂的词」。

- 站点：纯静态，无后端、无账号、无第三方脚本、无追踪
- 内容：20 条运镜 + 10 条风格
- 每条：中英术语、一句话、什么时候用、中英文提示词模板、容易翻车、参数建议
- 每条一个独立静态页，可被搜索引擎索引、可直接分享链接

## 目录

```
data.js              ← 内容唯一来源（改动只改这里）
build.mjs            ← 零依赖生成器
src/style.css        ← 样式
src/app.js           ← 检索、筛选、一键复制
index.html           ← 生成产物：首页（全部条目）
reference.html       ← 生成产物：术语速查表
about.html           ← 生成产物：关于与更新
term/<id>.html       ← 生成产物：每条一个详情页
assets/              ← 生成产物：样式与脚本
sitemap.xml          ← 生成产物：仅设了 SITE_URL 时
robots.txt           ← 生成产物
```

生成产物不要手改，下一次 `node build.mjs` 会被覆盖。

## 构建与预览

```bash
node build.mjs
python3 -m http.server 18766 --bind 127.0.0.1
# 打开 http://127.0.0.1:18766/
```

部署到正式域名后带地址再构建一次，会额外产出 `sitemap.xml` 并在 robots 里写指引：

```bash
SITE_URL=https://example.com node build.mjs
```

`build.mjs` 会先删掉 `term/` 再重写，改名或删条目不会留下孤儿页。id 重复会直接报错退出。

## 加一条内容

在 `data.js` 的 `moves` 或 `styles` 里加一项，字段照抄现有条目：

| 字段 | 说明 |
| --- | --- |
| `id` | 用于生成 `term/<id>.html`，只能出现一次 |
| `zh` / `en` | 中英术语 |
| `group` | 分组，决定排序（见 `build.mjs` 的 `GROUP_ORDER`） |
| `one` | 一句话说明 |
| `when` | 什么时候用 |
| `keywords` | 风格关键词（仅风格类需要） |
| `promptZh` / `promptEn` | 中英提示词模板 |
| `fail` | 容易翻车，数组 |
| `params` | 参数建议 |

改完跑一次 `node build.mjs`。

## 搜索

站内检索是前端做的，把每条的中英术语、说明、模板、翻车点拼进 `data-item` 的 `data-hay`，空格分词后任一命中即算匹配。所以「绕着人转」「dolly」「水墨」都能搜到。按 `/` 聚焦搜索框。

## 明确没做的

- **出片示例还没有。** 要有真实生成素材才有说服力，编示意图是骗人的，所以先空着。
- **提示词未逐条真机验证。** 模板按生成模型的常见表现写，「容易翻车」属经验判断，不是官方限制。
- 未按模型（可灵 / 即梦 / Runway / Sora）分版本，目前只有中英两版通用模板。
- 没有收藏、投稿、评论、付费、后台。
